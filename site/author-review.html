Author review, rereading and corrections

Review is substantive human work, not merely prompting. Reading, checking claims, taking responsibility for the content, making corrections and reviewing those corrections are distinct activities. API timing does not measure them.

Git revisions establish the review workload, not whether reading happened. The baseline assumes one contextual reading pass per version of each level-two source section. It counts the latest text once, plus the previous text of each changed or removed section. Unchanged sections, whitespace-only edits and section renumbering add no pass. This is a declared review policy, not a measured minimum of actual human time.

The author reports rereading some sections two or three times. Those reads may already be represented by section revisions, so additional passes default to zero. Add them only for reading beyond the version-based baseline. Only the main report is selected by default.

{{REVIEW_SENSITIVITY}}

Revision baseline = current words + superseded/removed section words. Reading minutes = (baseline word exposures + current words × extra-reread fraction × extra passes) ÷ words per minute. Add only separately entered, non-overlapping checking/editing minutes.

Reference: Brysbaert (2019), review and meta-analysis of reading rate. The 238 words/minute reference and 175-300 sensitivity range concern adult English silent nonfiction reading, not technical review or fact-checking productivity.

Counts cover selected Markdown source prose, headings, tables and captions through the audit's material commit, not today's rendered pages. Bibliography, citation markers, image pixels and code blocks are excluded. Generated-only financial tables, charts, layout, code, external sources, uncommitted drafts and later changes are not counted. Mechanical wording edits are included when section text changes. A section title change is recorded as removal/addition, retaining one pass per version rather than a whole-document reread per commit.

{{REVIEW_EVIDENCE}}

Do not add this estimate to the interaction proxy or model elapsed time. Review can happen during model calls, inside the non-model residual, or outside recorded sittings. The quantities overlap and have different scopes. Actual prompting and actual review time remain unmeasured without an author time log. A word-based estimate does not certify that review occurred, that the content is correct, or that responsibility has been discharged.
